# 핏케어 루틴 보드

운동 전용 모바일 웹 프로젝트입니다. 날짜에 따라 오늘의 루틴이 자동으로 바뀌고, 운동 순서 체크/타이머/메모를 한 화면에서 사용할 수 있습니다.

## 실행

```bash
cd /Users/hyunjae/projects/fitness-care-web
npm run dev
```

브라우저에서 `http://localhost:4173` 를 열면 됩니다.

## 현재 기능

- 요일별 자동 운동 루틴 변경
- 오늘 컨디션 기준 강도 선택
- 강도에 맞게 조정되는 운동 처방
- 월/화/수/목/금/토/일 주간 스케줄 선택 보기
- 오늘 운동 진행률과 다음 운동 안내
- 오늘 운동 순서 체크리스트
- 30초/60초 휴식 타이머
- 오늘 운동 메모와 이번 주 회고
- 이번 주 완료 횟수 확인
- 모바일 우선 UI
- 모든 기록은 브라우저 `localStorage`에 저장

## 참고

현재는 PWA/앱 설치 기능을 제거한 일반 모바일 웹입니다. 캐시 꼬임을 줄이고 최신 화면이 바로 반영되도록 유지합니다.
