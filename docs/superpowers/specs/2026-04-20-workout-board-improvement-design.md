# 운동 보드 개선 디자인 스펙

## 목표

현재 앱의 강점인 `오늘 운동을 바로 시작하게 만드는 보드` 성격은 유지하면서, 아래 세 가지를 강화한다.

1. 기록과 성취감 강화
2. 초보자 진입 부담 완화
3. 전체 UI를 더 앱답고 정제된 경험으로 개선

이번 개선의 핵심 방향은 `오늘 루틴 중심 + 상단 강도 선택 + 하단 주간 성취` 구조다.

## 제품 방향

앱의 첫인상은 기록 앱보다 `오늘 해야 할 운동을 바로 실행하게 만드는 코치형 보드`에 가깝게 유지한다.

다만 기존 구조는 체크리스트와 타이머는 잘 보이지만, 사용자가 아래 내용을 충분히 느끼기 어렵다.

- 오늘 운동을 어떤 강도로 해야 하는지
- 지금 어디까지 진행했는지
- 이번 주 전체 흐름에서 오늘 운동이 어떤 의미인지
- 운동 후 어떤 기록이 남는지

개선 후에는 첫 화면에서 아래 메시지가 분명해야 한다.

`오늘 이 루틴을, 지금 컨디션에 맞는 강도로, 바로 시작하면 된다.`

## 사용자 가치

### 1. 운동 시작이 쉬워야 한다

사용자는 앱을 열고 복잡한 판단을 반복하지 않아야 한다.  
운동 시작 전 한 번만 강도를 정하고, 그 뒤에는 제시된 루틴을 따라가기만 하면 된다.

### 2. 진행 중 성취가 보여야 한다

운동 도중에는 `오늘 완료 퍼센트`, `세트/동작 진행`, `다음 운동`이 계속 보여야 한다.

### 3. 운동 후 축적감이 남아야 한다

하루 운동이 끝나면 그 기록이 `이번 주 완료 횟수`와 `이번 주 회고`로 연결되어야 한다.

## 추천 접근

세 가지 접근을 검토했고, 아래 안을 채택한다.

### 채택안

`오늘 루틴 중심 + 상단 강도 선택 + 하단 주간 성취`

이 안은 현재 앱의 빠른 실행감은 유지하면서도, 사용자가 원한 기록 강화와 초보자 배려를 가장 자연스럽게 추가할 수 있다.

### 채택 이유

- 기존 단일 페이지 흐름을 크게 깨지 않는다.
- 상단에서 강도를 한 번만 고르게 해 초보자 부담을 줄인다.
- 오늘 운동의 진행감과 주간 성취를 자연스럽게 연결할 수 있다.
- 현재 코드 구조에서도 무리 없이 단계적으로 구현 가능하다.

## 정보 구조

화면은 아래 순서로 구성한다.

1. 오늘 루틴 히어로
2. 오늘 강도 선택
3. 운동 순서 체크리스트
4. 타이머 및 빠른 자세 팁
5. 오늘 메모
6. 이번 주 성취 영역

## 화면 설계

### 1. 오늘 루틴 히어로

첫 화면의 주인공이다.

포함 요소:

- 오늘 루틴 이름
- 루틴 카테고리
- 오늘 진행률
- 다음 운동
- 시작 또는 이어하기 CTA

히어로는 사용자가 앱을 열자마자 `무엇을 해야 하는지`를 이해하게 만들어야 한다.

### 2. 오늘 강도 선택

히어로 바로 아래에 배치한다.

선택지는 세 가지다.

- 가볍게
- 보통
- 집중

각 선택은 단순 라벨이 아니라 그날 처방을 바꾼다.

- `가볍게`: 반복 수, 유지 시간, 라운드 수를 낮추고 심리적 부담을 줄이는 문구를 제공
- `보통`: 현재 기본 루틴에 가장 가까운 기준값
- `집중`: 반복 수 또는 유지 시간을 소폭 높이고 좀 더 적극적인 안내 문구를 제공

이 선택은 하루에 한 번만 하게 만드는 것이 원칙이다.

### 3. 운동 순서 체크리스트

현재 앱의 핵심 경험을 유지한다.

다만 각 운동 항목은 선택한 강도에 맞는 처방을 반영해야 한다.

운동 카드에 포함할 내용:

- 운동 이름
- 현재 강도 기준 처방
- 자세 큐
- 다음 운동 또는 완료 상태 배지

### 4. 타이머 및 빠른 자세 팁

기존 구조는 유지하되, 오늘 루틴 중심 흐름을 방해하지 않도록 보조 도구 성격을 분명히 한다.

타이머는 빠르게 접근 가능해야 하지만, 화면의 주인공이 되어서는 안 된다.

### 5. 오늘 메모

오늘 운동이 끝난 뒤 짧게 남기는 회고 메모 영역이다.

메모는 자유 입력으로 유지하되, 플레이스홀더는 아래처럼 부담을 낮추는 방향으로 조정한다.

- 오늘 가장 힘들었던 동작
- 생각보다 괜찮았던 동작
- 다음에 조절하고 싶은 점

### 6. 이번 주 성취 영역

화면 하단에 배치한다.

포함 요소:

- 이번 주 완료 횟수
- 주간 진행 흐름 요약
- 이번 주 회고

여기서 `이번 주 회고`는 처음부터 AI 요약을 만들지 않는다.  
해당 주에 남긴 하루 메모들을 주간 단위로 묶어 보여주는 구조로 시작한다.

## 상호작용 흐름

### 앱 진입

1. 사용자가 앱을 열면 오늘 루틴 히어로를 본다.
2. 그 아래에서 `가볍게 / 보통 / 집중` 중 하나를 선택한다.
3. 선택 즉시 오늘 처방이 갱신된다.
4. 사용자는 체크리스트를 따라 운동을 진행한다.

### 운동 진행

1. 운동 항목을 완료할 때마다 상단 진행률이 갱신된다.
2. 다음 운동 안내가 함께 갱신된다.
3. 타이머는 필요할 때 즉시 시작할 수 있다.

### 운동 종료

1. 사용자가 오늘 운동 완료를 체크한다.
2. 이 기록은 해당 주의 완료 횟수에 반영된다.
3. 사용자가 메모를 남기면 주간 회고에 포함된다.

## 데이터 모델 변경

기존 날짜별 로그 구조를 유지하면서 아래 필드를 추가한다.

- `intensity`: 그날 선택한 강도 (`light`, `normal`, `focus` 등)
- 강도별 처방 기준에 맞춘 체크 상태

하루 로그는 최소 아래 정보를 가져야 한다.

- note
- completed
- sessionDone
- intensity

## 계산 규칙

### 오늘 진행률

선택한 강도 기준으로 생성된 오늘 체크리스트 항목 중 완료된 항목 비율로 계산한다.

### 이번 주 완료 횟수

현재 주간 범위 내에서 `sessionDone`이 참인 날짜 수를 합산한다.

### 이번 주 회고

현재 주간 범위 내에서 비어 있지 않은 `note` 값을 날짜순 또는 최신순으로 묶어 보여준다.

## 강도 변경 규칙

강도 변경은 사용자가 헷갈리기 쉬운 지점이므로 명확한 규칙이 필요하다.

채택 규칙:

`해당 날짜에 이미 체크한 운동이 있는 상태에서 강도를 바꾸면, 그날 체크리스트 상태를 초기화한다.`

필요한 UX:

- 이미 진행 중인데 강도를 바꾸려는 경우 확인 문구 제공
- 사용자가 동의하면 체크 상태 초기화 후 새 강도 기준 처방 적용

이 규칙은 가장 단순하고 예측 가능하며, 구현 복잡도도 낮다.

## 오늘이 아닌 요일 처리

현재처럼 다른 요일을 미리 보는 기능은 유지할 수 있다.  
다만 개선 후에도 핵심 원칙은 동일하다.

- 오늘이 아닌 요일은 `미리보기` 중심
- 체크, 완료, 강도 선택 같은 행위는 오늘 기준에서만 활성화

## 오류 및 예외 처리

- 로컬 저장소 데이터가 없거나 손상된 경우 기본 상태로 복구
- 강도 값이 누락되면 `보통`으로 간주
- 주간 회고에 메모가 없으면 비어 있는 상태 문구 표시
- 주간 완료 횟수가 없더라도 빈 상태가 어색하지 않게 설계

## 테스트 범위

최소 검증 범위는 아래 세 가지다.

1. 강도 선택에 따라 운동 처방이 달라지는지
2. 오늘 완료가 이번 주 완료 횟수에 반영되는지
3. 메모가 이번 주 회고에 정상적으로 모이는지

추가로 가능하면 아래도 확인한다.

- 강도 변경 시 체크 상태 초기화 동작
- 오늘이 아닌 요일에서 수정 기능이 비활성화되는지
- 새 날짜로 넘어갔을 때 로그가 정상 생성되는지

## 구현 메모

- 현재 앱은 `src/app.js` 중심의 단일 페이지 구조이므로, 이번 개선도 과도한 분리보다 책임이 분명한 함수 단위 정리에 우선순위를 둔다.
- 강도별 처방은 기존 `routineCatalog`를 확장하는 방식이 자연스럽다.
- 주간 성취 계산은 별도 헬퍼 함수로 분리하는 편이 안전하다.
- UI는 기존 다크 톤을 유지하되, 오늘 루틴 히어로와 주간 성취 섹션의 위계를 더 선명하게 만든다.

## 범위 밖

이번 스펙에는 아래 항목을 포함하지 않는다.

- 서버 저장 또는 계정 연동
- AI 기반 회고 요약
- 운동 영상, 자세 애니메이션, 소셜 기능
- 오늘이 아닌 날짜의 과거 로그 상세 분석

## 성공 기준

이번 개선이 잘 됐다고 볼 수 있는 기준은 아래와 같다.

- 사용자가 앱을 열고 바로 오늘 운동을 시작할 수 있다.
- 초보자도 강도 선택 한 번으로 부담을 낮출 수 있다.
- 운동 중에는 오늘 진행감이 분명하게 보인다.
- 운동 후에는 이번 주 완료 횟수와 회고가 남아 축적감이 생긴다.
